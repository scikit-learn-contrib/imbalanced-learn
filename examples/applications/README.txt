Resampling comparison
---------------------

The plot_resampling_comparison.py example uses the Breast Cancer Wisconsin
dataset to compare four approaches for handling class imbalance:

- no resampling
- random oversampling
- random undersampling
- SMOTE

The example evaluates each approach using balanced accuracy, F1 score, and
geometric mean. It also produces a bar chart to make the comparison easier
to understand. The example demonstrates that resampling methods should be
evaluated carefully because they do not always improve every metric... _realword_examples:
